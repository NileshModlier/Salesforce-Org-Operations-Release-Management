# Portfolio showcase

Case-study site for Salesforce Org Operations & Release Management. It is a portfolio page, not a product.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production

```bash
npm run build
npm run start
```

On Vercel, set the project root to `showcase`. The app uses the App Router and needs no environment variables.

## Profile links

GitHub and LinkedIn URLs live in `src/lib/site.ts`. Replace the placeholders with the public profile URLs before sharing the site.
