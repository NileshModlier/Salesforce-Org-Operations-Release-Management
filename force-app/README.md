# force-app

Default Salesforce DX package directory.

M2 metadata: fields, standard value sets, validation rules, layouts, and Lightning record pages.

M3 metadata: four Draft flows and their flow tests, L1 and L2 case queues, minimum-access profiles, four permission sets, and four permission set groups.

M4 metadata: ten reports, two dashboards, and three reporting permission sets. The reporting sets are added to the Sales Rep, Support Lead L2, and Ops Admin groups. Support Agent L1 has no reporting set.

No Flosum deployment and no AI helper are in this package. Release runbooks, outside this package, are in `release/`.
